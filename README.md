# 우사기 듣기평가 1.0

첨부된 제초 자격증 React / TypeScript / Vite 프로젝트를 바탕으로 만든 듣기평가 전용 버전입니다.

## 실행

Node.js 22.12 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

배포 빌드: `npm run build`. Vercel 프레임워크는 Vite, 출력 폴더는 dist입니다.

## 현재 상태

- 소개 → 영상 객관식 10문제 → 성적표 / 정답 해설 / PNG 저장 / 공유
- 답안은 이전 문제에서 수정할 수 있으며, 마지막에 일괄 채점합니다.
- 한 문제당 10점입니다. 자동 재생하지 않으며 기본 영상 컨트롤을 사용합니다.
- 실제 영상은 첨부되지 않았습니다. 제공되는 10개 문항의 질문·보기·정답·해설은 모두 제작용 예시이며 공식 해석이 아닙니다.
- 이름과 답안은 현재 페이지 메모리에만 두며 기존 자격증 저장 데이터는 읽거나 수정하지 않습니다.

## 실제 문제 교체

`public/questions.json`의 10개 항목을 수정합니다. 각 항목:

```json
{
  "id": 1,
  "prompt": "이 장면에서 우사기는 무엇을 말하고 있을까요?",
  "choices": ["보기 1", "보기 2", "보기 3", "보기 4", "보기 5"],
  "answer": 1,
  "explanation": "2번이 정답인 이유를 입력합니다.",
  "video": "videos/q01.mp4"
}
```

`answer`는 0부터 시작합니다. 0=1번, 1=2번, …, 4=5번입니다.
각 문제에는 고유 id와 다섯 보기가 필요합니다. 총 10개를 유지해 주세요.
영상은 `public/videos/q01.mp4` ~ `q10.mp4`로 넣고 JSON의 video를 연결합니다.
브라우저 호환성을 위해 H.264 영상 / AAC 오디오 MP4를 권장합니다. 영상 비율은 16:9 영역 안에서 원본 비율을 유지합니다.
영상 경로를 전부 연결하면 예시 상태 표시는 사라집니다. 영상과 실제 내용에 맞춰 정답·해설도 반드시 수정해 주세요.

## 배경 영구 교체

- 가로: `public/assets/bg-web-high.png`
- 세로: `public/assets/bg-mobile-high.png`

같은 이름으로 교체하면 됩니다. 600px 이하 화면은 세로 배경을 사용하며, cover 방식이므로 가장자리가 일부 잘릴 수 있습니다.

## 색상과 디자인

`src/styles.css` 맨 위 변수에서 변경합니다.

- `--ink`: 글자 / 테두리
- `--accent`: 주요 버튼 (살구색)
- `--secondary`: 보조 버튼 (연보라)
- `--paper`: 종이색

기존 따뜻한 배경과 우사기 프로필 에셋을 재사용하고, 버튼·카드·보기·진행률은 새로 구성했습니다. 기존 자격증 모듈은 제거했습니다.

## 참고

`THIRD_PARTY_NOTICES.txt`는 원본의 고지 문서를 보존한 것입니다. 첨부된 파일과 캐릭터 이미지에 관한 권리 상태를 새롭게 확인한 것은 아닙니다.

## 1.1 결과 자격증 업데이트

결과 이름은 우사기 언어평가입니다. 기존 제초 자격증 테두리와 왕관 형태를 재사용하여, 우사기 이미지와 수험생 이름·급수·점수를 넣습니다. resultAvatar에 PNG 자격증 이미지를 출력하며 같은 이미지를 저장합니다.

점수 구간: 0점 꽝 / 1~20점 5급 / 21~40점 4급 / 41~69점 3급 / 70~89점 2급 / 90~100점 1급. 현재 10문항이므로 실제 점수는 10점 단위입니다.

## 1.4 업데이트
첨부된 실제 영상 10개와 문제 데이터를 유지했습니다. 자격증 이름과 급수 간격을 조정하고 이름 옆 점수를 제거했습니다. 영상 원본 비율과 첫 프레임 포스터를 적용했습니다. 영상 교체 시 questions.json의 videoAspect와 poster도 갱신하거나 두 항목을 삭제해 자동 원본 비율을 사용하세요.

## 1.5 배경 업데이트
가로 배경: 꽃잎 흩날리는 꿀빛 부두의 세 친구. 세로 배경: 꿀빛 나무 부두의 세 친구. 화면 너비 600px 이하에서 세로 배경으로 전환합니다. 배경의 원본 색감이 잘 보이도록 덮개 색의 투명도를 조정했습니다.

## 1.7 영상 플레이어 업데이트
기본 영상 컨트롤을 제거했습니다. 재생 전에는 중앙 재생 버튼, 재생 중에는 가림 없는 영상, 일시정지 시 이어 듣기 버튼, 종료 후에는 영상 아래 다시 듣기 버튼을 표시합니다. 영상 영역을 누르거나 키보드로 버튼을 작동하여 재생/일시정지할 수 있습니다. 자동 반복은 사용하지 않습니다.
